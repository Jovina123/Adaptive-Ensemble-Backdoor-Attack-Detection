1 Dataset

Expected keys: X_train, Y_train, X_test, Y_test (one-hot labels). For detection-only you can get away with just X_test/Y_test.

2 Dataset condition

Poisoning happens on-the-fly during training (recommended). Use the button below only if you also want a standalone poisoned .h5 file.

3 Train

Or skip training and use an existing model file below.

4 Run Detector

Runs Neural-Cleanse-style trigger reverse-engineering for every class, then flags outliers with MAD. This can take a while (steps × num_classes).
Scanning a handful of labels instead of every class runs much faster — useful for testing. Include at least ~5-10 labels for the outlier flagging to be meaningful.
If the selected model was poisoned via the Train panel, its true backdoored label(s) are picked up automatically from training metadata and Accuracy/Precision/Recall/F1/FPR/FNR are computed without typing anything here. Only fill this in to override, or when testing a model trained outside this app.
